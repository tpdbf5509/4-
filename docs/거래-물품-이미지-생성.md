# 거래 물품 이미지 생성 요청

최초 요청 도구는 Google Flow였다. 2026년 10월 22일 사용자가 내장 이미지 생성 도구로 변경을 요청해 물품 아이콘을 생성했다. 생성 문구에 **2D 도트형 RPG 게임**을 명시했다.

실제 사용 파일: `public/assets/game/rpg/items/trade-icons.webp`. 1254×1254 투명 WebP이며 6열×6행이다. 자르지 않고 거래 창에서 칸별로 표시한다. 물품 연결표는 `src/TradePanel.jsx`의 `ITEM_ART`와 `WEAPON_ART`에 있다. 기존 특별 무기와 방어구 그림은 유지한다.

## 거래 UI 시안

> 첨부한 손그림 배치를 참고해 2D 도트형 RPG 게임의 개인 거래 UI 시안을 만들어 주세요. 화면은 따뜻한 짙은 갈색 바탕과 톤다운된 금빛의 얇은 테두리로 통일합니다. 왼쪽 절반에는 주문서·아이템·물약 탭과 정사각형 물품 칸을 3열 3행으로 놓습니다. 칸 안에는 양피지 주문서, 빨간 물약, 검, 방어구, 강화석 등 선명한 2D 픽셀 아트 물품 아이콘을 넣고 일부 칸은 비워 주세요. 오른쪽 절반은 위에 상대방 물품, 가운데에 위아래 교환 화살표, 아래에 내 물품 영역을 둡니다. 상대방 물품과 내 물품도 같은 정사각형 아이콘 칸을 사용합니다. 기존 레트로 RPG의 가방 UI처럼 보이게 하고 3D·실사·현대적인 회색 대시보드 스타일은 쓰지 마세요. 강조색은 거래 확인 버튼 한 곳에만 사용합니다.

## 실제 게임용 물품 아이콘

> 2D 도트형 RPG 게임에서 사용할 인벤토리 물품 아이콘을 만들어 주세요. 레트로 픽셀 아트이며 픽셀 경계가 선명해야 합니다. 기존 게임의 따뜻한 갈색 가방과 금빛 테두리 안에서 잘 보이는 톤다운 색을 사용하세요. 물품마다 정사각형 64×64 픽셀이며 가운데에 하나씩 배치합니다. 글자, 숫자, UI 테두리, 그림자 배경은 넣지 마세요. 투명 배경으로 만들어 주세요. 주문서 두 종류(지역 워프용 양피지 두루마리, 강화 하락 방지용 봉인 두루마리), 빨간 회복 물약, 큰 빨간 회복 물약, 파란 지혜 물약, 주황 힘의 물약, 보라 집중 물약, 초록 이동 속도 물약, 반투명 투명화 물약, 스탯 초기화 물약, 파란 강화석, 붉은 심장결정, 갈색 동물 털, 흰 송곳니를 각각 구분할 수 있게 그려 주세요. 3D 렌더링, 실사, 매끈한 벡터, 흐릿한 안티앨리어싱은 사용하지 마세요.

특별 무기와 방어구는 기존 그림을 재사용한다. 기본 무기 7종도 새 시트에 포함했다. 주문서 2종, 물약 11종, 재료 13종과 기본 무기 7종을 연결했다. 마지막 칸 3개는 동전·열쇠·가죽 주머니다.
