# 공허의 관측자 — 정식 그림 규격

11월 5일에 Codex(`codex-image` 스킬)로 만든 **정식 그림**으로 바꿨다(보스 몸 · 무기 3종 · 방어구 4종 · 입은 모습). 원본은 `design/void/*-src.webp`, 묶는 스크립트는 `design/void/build-art.py`.
처음 넣었던 임시 도트 그림(`make-temp-art.py`)은 기록으로만 남긴다. 아래 규격은 그림을 다시 뽑을 때 **같은 경로 · 같은 크기**로 덮어쓰면 코드를 고치지 않아도 바뀐다는 뜻이다.
정식 그림은 도트풍이 아니라 다른 월드보스(뇌조 등)와 같은 그려진 그림 화풍이다.
공통: 투명 배경 WebP, 도트풍(기존 월드보스 그림과 같은 두께의 검은 보라 외곽선), 색은 검보라 `#2a1458` · 보라 `#6a3fc2` · 연보라 `#a077f0` · 빛 `#d3b8ff` · 포인트 금색 `#c4a86c`.

## 1. 보스 몸 — `public/assets/game/rpg/boss/void-observer.webp`
- 1024×512, 2열×1행. 왼쪽 기본 자세 · 오른쪽 공격 준비 자세. 칸 512×512.
- 발(몸 맨 아래) 기준점은 칸 높이의 84% 지점, 가운데 정렬. 코드 값: `worldBossData.js` `art = { cols: 2, rows: 1, size: 700, feet: [.84, .84] }`.
- 모습: 거대한 눈 하나가 박힌 검은 구체와 떠 있는 고리·파편. 날개나 팔이 칸 밖으로 잘리지 않게 칸 가장자리에서 20px 이상 띄운다.
- 기본 자세는 눈이 정면, 준비 자세는 고리가 벌어지고 눈동자가 밝아진다.

## 2. 장비 시트 — `public/assets/game/rpg/items/world-equipment.webp`
- 1916×1369, 7열×5행. 한 칸은 약 273.7×273.8. **5행(공허)만 새로 그린다.** 1~4행은 건드리지 않는다.
- 5행 0열 = 공허의 대검 · 1열 = 공허의 지팡이 · 2열 = 공허의 장궁 · 3~6열 = 차원의 지배자 투구 · 갑옷 · 바지 · 신발.
- 무기는 칸 가운데에 비스듬히 세워 그리고, 손잡이(쥐는 곳)와 끝 위치가 `rpgArt.js` `WEAPON_GRIP`(128 기준 좌표)과 맞아야 한다.
  - 대검 `[25,105,109,19]` · 지팡이 `[64,113,64,12]` · 장궁 `[32,64,79,13]`(장궁은 시위가 세로 중심선)
  - 다른 위치로 그리면 `WEAPON_GRIP`을 같이 고친다.
- 방어구는 가운데 정렬, 칸 안쪽 20px 여백.

## 3. 입은 방어구 — `public/assets/game/rpg/wear/void.webp`
- 1536×1536, 4열(앞 · 옆 · 뒤 · 돌아섬)×3행(투구 · 갑옷 · 신발), 칸 384×512.
- 기존 `wear/dragon.webp` 등과 같은 몸 틀(캐릭터 프레임)에 맞춘다. 바지는 갑옷 행에 포함한다.

## 4. 연출(그림 파일 없음)
무기 스킬·패시브 6종(`sk_void_*`)과 보스 바닥 표시(중력 소용돌이 · 절단선 · 포탈 · 안전 구역 · 충격 고리 · 문장)는 코드가 도트로 직접 그린다(`voidWeaponArt.js` · `voidBossArt.js`). 파일 그림이 필요하면 pixelfx로 시트를 뽑아 `rpg/effects/world-boss/`에 두고 그리기 코드를 바꾼다.
- 안전 구역은 항상 밝은 금빛 테두리 + 안쪽 연보라 면으로, 위험 구역(어두운 보라)과 확실히 구분한다.
