# 「네 갈래 방어선」 기능 명세서

| 항목 | 내용 |
|---|---|
| 문서 목적 | 게임이 현재 제공하는 기능과 규칙을 한곳에 정리해, 개발 · 기획 · 시험이 같은 기준으로 논의하게 한다 |
| 기준 | 브랜치 `claude/4-player-coop-defense-1x89l5` · 작성일 2026-10-01 · 업데이트 창 기준 9월 30일 변경까지 반영 |
| 근거 | 소스 코드(`src/`)에서 직접 확인한 내용만 적었다. 수치는 `src/game/world.js` · `logic.js` · `rpg.js` 의 값이다 |
| 읽는 법 | 기능마다 ID(예: `DEF-LOBBY-03`)를 붙였다. 표의 "구분"은 **필수**(기본 동작) · **선택**(켜고 끌 수 있거나 조건부) 이다 |

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 이름 | 네 갈래 방어선 |
| 한 줄 소개 | 북 · 동 · 남 · 서 네 갈래 길로 밀려오는 적을 최대 네 명이 협동해 막는 실시간 디펜스. 별도 모드로 RPG 사냥 모드가 있다 |
| 모드 | ① 방어전(협동 디펜스) ② RPG 모드(광장 · 사냥터) |
| 플랫폼 | 웹 브라우저(PC · 휴대폰). 설치 없이 주소로 접속 |
| 인원 | 방어전 최대 4명(병과 11종 가운데 골라 맡음) · RPG는 서버마다 최대 16명(서버 5개) |
| 화면 | 방어전 판 1160 × 760(논리 좌표). 화면 크기에 맞춰 늘어나고, 휴대폰은 가로로 돌리면 커진다 |
| 접속 | 방어전은 방 코드 4글자(영문 대문자 · 숫자)로 입장. 초대 링크 `?room=코드` 는 코드 칸을 미리 채워 줄 뿐 자동 입장하지 않는다. RPG는 방 코드 없이 "RPG 서버"에 바로 들어간다 |
| 저장 | 로그인 계정은 없다. RPG 캐릭터만 이름 + 숫자 5자리 코드로 서버(Supabase)에 남아 다른 기기에서 이어 할 수 있다. 홈 이름 · 소리 설정 등은 사용자 기기의 브라우저 저장소에 남는다 |

### 1.1 기술 구성

| 구분 | 내용 |
|---|---|
| 화면 | React 19 · Vite 8. 판은 `<canvas>` 에 직접 그린다(`src/game/art.js`, `rpgArt.js`) |
| 규칙 | 순수 자바스크립트(`world.js` 상수 · `logic.js` 방어전 · `rpg.js` RPG) |
| 실시간 통신 | Supabase Realtime 채널 1개 = 방 1개(`flg:<코드>`). 접속자 목록은 presence, 나머지는 broadcast. 서버에 테이블 · 계정 없음 |
| 판정 방식 | **방장 한 명이 모든 판정**을 하고, 손님은 입력을 보내고 결과(스냅샷)를 받아 그린다. 스냅샷과 연출 이벤트를 한 메시지로 보낸다(방어전 초당 12회 · RPG 는 인원에 따라 3~10회) |
| 소리 | 파일 없이 웹오디오로 즉석 합성(`sfx.js`) |
| 그림 | `public/assets/` 의 이미지. 판 위 요소는 `public/assets/game/`(움직이는 것은 36프레임 시트 + `manifest.json`), 파일이 없으면 코드로 그린 그림으로 대신 그린다 |
| 배포 | GitHub 브랜치에 push 하면 Vercel 이 자동 배포(프로젝트 `four-lane`) |
| 의견 수집 | Supabase `feedback` 표(쓰기만 열려 있고 읽기는 막힘, `supabase/feedback.sql`) |

## 2. 사용자 · 권한

| 역할 | 정의 | 할 수 있는 것 |
|---|---|---|
| 방장 | 방을 만든 사람(테스트 서버는 먼저 들어온 사람) | 모든 판정을 맡고, 라운드 · 난이도 · 시작 · 일시정지 · 속도를 정한다 |
| 손님 | 코드로 들어온 사람 | 병과 선택, 자기 탑 조작, 대기실 복귀 동의, 결과 화면 보기. 라운드 · 난이도 · 시작 · 일시정지 · 속도는 못 바꾼다(버튼이 비활성) |
| 구경꾼 | 정원(4명)이 찬 뒤 들어온 사람 | 판을 보기만 한다 |
| 테스트 서버 사용자 | 방 코드 `TEST` 에 비밀번호로 들어온 사람 | 골드 무제한 등 실험 도구를 쓴다(8장) |
| RPG 서버 참가자 | RPG 서버 1~5에 들어온 사람 | 자기 캐릭터로 사냥한다. 서버가 가득 차면(16명) 다음 서버로 넘어간다 |

방장이 나가거나 연결이 끊기면 손님 화면에 "방장과의 연결이 끊긴 것 같습니다…"가 뜬다(6초 동안 소식이 없을 때).

## 3. 화면 흐름

```
홈 ──새 방 만들기──▶ 대기실 ──방어 시작──▶ 방어전 판 ──종료──▶ 결과 ──대기실로──▶ 대기실
 │                                              │
 │                                              └ 보스 결전(웨이브 중 전환) ▶ 능력 선택 ▶ 다음 웨이브
 ├──코드로 입장──▶ 대기실(손님)
 └──RPG 모드──▶ 캐릭터 만들기 ──▶ RPG 서버 입장 ──▶ 광장 ⇄ 토끼 사냥터 ⇄ 늑대 사냥터
```

| 화면 | 설명 |
|---|---|
| 홈 | 이름 · 새 방 만들기 · RPG 모드 · 코드 입장 |
| 대기실 | 방 코드 · 라운드 · 난이도 · 병과 11종 카드 · 시작 · 업데이트 · 의견 |
| 방어전 판 | 캔버스 판 + 성채 · 웨이브 · 속도 단추 + 참가자 카드 |
| 보스 결전 | 판이 결전장으로 바뀌고 각자 캐릭터를 직접 움직여 보스를 때린다 |
| 능력 선택 | 보스를 잡은 뒤 각자 카드 3장(지옥 2장) 중 하나를 22초 안에 고른다 |
| 결과 | 성공 / 성채 함락 / 전멸 + 의견 칸 + 대기실로 |
| RPG | 캐릭터 만들기 → 광장 → 토끼 사냥터 → 늑대 사냥터 |

## 4. 공통 기능

### 4.1 홈

| ID | 기능 | 구분 | 설명 |
|---|---|---|---|
| CMN-HOME-01 | 이름 입력 | 필수 | 최대 8자, 비우면 "수비대원". 방에 들어갈 때 기기에 저장되어 다음에 채워 준다 |
| CMN-HOME-02 | 새 방 만들기 | 필수 | 4글자 방 코드를 만들고 방장이 된다. 코드는 헷갈리는 글자(0/O, 1/I)를 뺀 32자에서 뽑는다 |
| CMN-HOME-03 | 코드로 입장 | 필수 | 4글자 입력 후 입장(Enter 가능). 코드가 4글자가 아니면 입장 단추 비활성. 4초 안에 방 소식이 없으면 "그 코드의 방을 찾지 못했습니다" 안내 |
| CMN-HOME-04 | RPG 모드 들어가기 | 필수 | 캐릭터 만들기 화면으로 간다. 저장된 캐릭터가 있으면 "내 캐릭터 — 이름 Lv." 한 줄로 보여 준다. 코드 칸에 `RPG1`~`RPG5` 를 넣고 입장해도 같은 화면으로 간다 |
| CMN-HOME-05 | 테스트 서버 입장 | 선택 | 코드에 `TEST` 를 치면 비밀번호 칸이 나온다. 맞으면 이 기기가 기억해 다시 묻지 않는다(8장) |
| CMN-HOME-06 | 서버 설정 점검 | 필수 | 서버 주소 · 키가 없으면 "서버 설정이 필요합니다" 안내 |

### 4.2 방 연결과 동기화

| ID | 기능 | 구분 | 설명 |
|---|---|---|---|
| CMN-NET-01 | 방 = 채널 | 필수 | 같은 코드의 사람은 한 채널에 모인다. 탭마다 서로 다른 참가자(탭 단위 임시 ID) |
| CMN-NET-02 | 방장 판정 | 필수 | 판정은 방장 한 명만 한다. 손님은 입력(`input`)을 보내고 스냅샷을 받아 그린다 |
| CMN-NET-03 | 스냅샷 | 필수 | 방장이 상태와 연출(`o`)을 한 메시지로 보낸다. 방어전은 초당 12회. RPG 는 `48 ÷ 서버 인원`회(3~10회)로 줄인다. 실시간 서버(Supabase 무료)는 프로젝트 전체에서 초당 메시지 100개가 한도이고 넘으면 연결을 끊기 때문이다(받는 사람마다 1개로 센다). 손님 화면은 받은 값으로 부드럽게 따라간다 |
| CMN-NET-08 | 잃은 입력 되살리기 | 필수 | RPG 스냅샷에 방장이 아는 손님의 이동 방향 · 평타 누름을 싣는다. 손님은 내 키와 다르면 0.7초 뒤 다시 보낸다. 연결이 잠깐 끊겨 입력을 잃어도 걷기 · 멈춤 · 평타가 되살아난다 |
| CMN-NET-09 | 끊긴 사이 승계 막기 | 필수 | 내 연결이 끊긴 사이에는 방장을 이어받지 않는다. RPG 방장의 "살아 있음" 소식은 2초마다 보낸다 |
| CMN-NET-04 | 연출 이벤트 | 필수 | 폭발 · 숫자 · 배너 · 탄 같은 연출은 방장이 `out` 이벤트로 따로 보낸다 |
| CMN-NET-05 | 입장 · 퇴장 감지 | 필수 | 창을 닫거나 다른 곳으로 가면(`pagehide`) 곧바로 방을 떠난다 |
| CMN-NET-06 | 방장 요청 | 필수 | 손님은 "대기실로 돌아가기"만 방장에게 요청할 수 있다. 라운드 · 난이도 · 시작 요청은 받지 않는다 |
| CMN-NET-07 | 공용 서버 방장 | 선택 | 테스트 서버(`TEST`)와 RPG 서버(`RPG1`~`RPG5`)는 모두가 같은 코드로 들어온다. 먼저 있는 사람이 방장이 되고, 동시에 들어오면 아이디가 작은 쪽이 방장이 된다. 방장 정하기는 0.5초마다 다시 본다 — 접속자 목록에 응답 없는 사람(방금 닫은 탭 · 잠든 휴대폰)이 남아 있어도 그런 사람 한 명마다 2초씩만 더 기다린 뒤 방장이 된다. 방장이 둘 생기면 아이디가 큰 쪽이 물러난다. **RPG 서버는 방장이 나가거나 조용해지면 남은 사람이 이어받는다** |
| CMN-NET-08 | 개발용 로컬 전송 | 선택 | 개발 서버에서 `?net=local` 이면 같은 브라우저의 여러 탭이 서버 없이 한 방에 모인다 |

### 4.3 부가 기능

| ID | 기능 | 구분 | 설명 |
|---|---|---|---|
| CMN-SND-01 | 소리 켜고 끄기 | 선택 | 판 위 소리 단추. 설정은 기기에 남는다(`flg:mute`) |

## 5. 방어전

### 5.1 대기실

| ID | 기능 | 구분 | 설명 |
|---|---|---|---|
| DEF-LOBBY-01 | 방 코드 · 초대 | 필수 | 방 코드를 크게 보여 주고 "코드 복사" · "초대 링크 복사" 단추를 둔다 |
| DEF-LOBBY-02 | 라운드 수 | 필수 | 15 · 30 · 45 · 60 중 선택(기본 15). **방장만**. 길게 잡아도 마지막 웨이브의 세기는 같다(적이 세지는 속도가 완만해짐) |
| DEF-LOBBY-03 | 난이도 | 필수 | 쉬움 · 보통(기본) · 어려움 · 지옥 중 선택. **방장만**. 선택한 난이도의 설명을 옆에 보여 준다 |
| DEF-LOBBY-04 | 병과 카드 11종 | 필수 | 병과 하나가 탑 하나를 맡는다. 카드마다 이름 · 건설 비용 · 역할 · 설명 · 병과 스킬 · 캐릭터 그림 · 맡은 사람 표시. 빈 카드를 눌러 맡고, 다른 카드를 누르면 옮긴다 |
| DEF-LOBBY-05 | 정원 | 필수 | 4명까지 맡을 수 있다. 정원이 차면 남은 빈 카드는 잠기고(구경꾼) 들어온 사람은 구경만 한다 |
| DEF-LOBBY-06 | 자동 배정 | 필수 | 방장이 있는 방에 들어온 사람에게는 비어 있는 병과를 자동으로 하나 내어 준다(정원이 차 있으면 제외) |
| DEF-LOBBY-07 | 자세히 보기 | 선택 | 카드 오른쪽 아래 단추. 탑의 역할 · 건설과 강화 비용 · 사거리 · 피해 · 단계별 변화 · 병과 스킬을 창으로 보여 준다(Esc · 바깥 · 닫기). 선택은 바뀌지 않는다 |
| DEF-LOBBY-08 | 방어 시작 | 필수 | **방장만**. 한 명 이상 있어야 켜진다. 모두 판으로 들어간다. 손님은 비활성 단추("방장이 시작하기를 기다리는 중") |
| DEF-LOBBY-09 | 보스전 바로가기 | 선택 | "1차 보스전" · "2차 보스전" — 해당 보스를 처음 만나는 웨이브에서 곧바로 시작(시험용). **방장만** |
| DEF-LOBBY-10 | 나가기 | 필수 | 방을 떠나 홈으로 |

### 5.2 판 구조

| ID | 기능 | 설명 |
|---|---|---|
| DEF-MAP-01 | 성채 | 판 한가운데. 적이 성문 앞까지 오면 체력이 깎인다. 체력이 0이 되면 패배 |
| DEF-MAP-02 | 네 갈래 길 | 북 · 동 · 남 · 서 관문에서 성채로 직각으로 꺾이며 이어진다 |
| DEF-MAP-03 | 돌판(자리) | 58곳(북 11 · 동 18 · 남 12 · 서 17). 각자 자기 병과의 탑만 지을 수 있다 |
| DEF-MAP-04 | 자리 성격 | 자리마다 보너스가 다르다 — 아래 표 |

| 자리 | 조건 | 보너스 |
|---|---|---|
| 핵심 지점(11곳) | 여러 길이 걸친다 | 대포 폭발 범위 ×1.3 · 번개 연쇄 +1 · 화염 사거리 ×1.15 · 그 밖의 탑은 공격력 +12% |
| 집중 지점(14곳) | 한 길을 길게 굽어본다 | 공격 속도 +15% |
| 장거리 지점(24곳) | 길에서 물러나 있다 | 사거리 +18(궁수 · 저격에 유리) |
| 위험 지점(9곳) | 적이 스쳐 지나간다 | 공격력 +20% |

돌판에 처음 마우스를 올리면 그 자리의 성격을 짧게 알려 준다.

| DEF-CTL-04 | 팔기 | X · Delete · Backspace | 팔기 단추 |
| DEF-CTL-05 | 스킬 | Shift · E | 스킬 단추 |
| DEF-CTL-06 | 성채 강화 | 성채 단추 클릭 | 성채 단추 누르기 |
| DEF-CTL-07 | 대기실로 돌아가기 | 집 모양 단추(동의) | 같음 |

판정 · 입력은 모두 방장에게서 처리된다. 손님은 자기 커서를 먼저 움직여 보이게 하고(예측), 방장이 돌려주는 순번으로 어긋남을 바로잡는다.

### 5.4 진행 단계

| 단계 | 내용 |
|---|---|
| 준비(prep) | 웨이브 사이 준비 시간(난이도별 4~7초). 이번 웨이브에 올 적 미리보기가 뜬다. 이 동안 건설 · 강화 가능 |
| 교전(wave) | 적이 길을 따라 들어온다. 남은 적 수를 보여 준다. 건설 · 강화 · 스킬 계속 가능 |
| 보스 결전(arena) | 보스 웨이브(5의 배수 · 마지막)에는 길로 오는 대신 결전장이 열린다(5.9) |
| 능력 선택(reward) | 보스를 잡은 뒤. 먼저 보스를 누가 얼마나 때렸는지 기록(4초)을 보여 주고, 각자 능력 카드를 22초 안에 고른다 |
| 성공(clear) | 마지막 웨이브(대군주)를 격파 |
| 패배(over) | 성채 체력 0("성채 함락") 또는 결전장에서 모두 쓰러짐("전멸") |

웨이브 종류는 번호로 정해진다.

| 조건 | 종류 |
|---|---|
| 마지막 웨이브 | 대군주 결전 |
| 5의 배수 | 5·15·25… 오우거 지휘관 결전, 10·20·30… 대군주 결전(번갈아) |
| 4의 배수(5의 배수 제외) | 돌격 웨이브(빠른 고블린 떼) |
| 그 밖 | 보통 웨이브 |

- 보스를 하나 잡을 때마다 길로 오는 적이 세진다 — 체력은 난이도별로 +8% · +12% · +16% · +32%, 속도는 +4.5%(최대 +60%)씩(HUD에 표시).
- 적의 세기는 `1.155^((웨이브−1) × 15 ÷ 라운드 수)` 로 오른다. 라운드 수가 길어도 마지막 웨이브의 세기는 같다.
- 적 수는 사람 수와 난이도로 정해진다. 길은 웨이브가 진행되며 2 → 3 → 4곳이 열리고(사람 수보다 많이 열리지 않음) 몹은 그 길들에 번갈아 나온다.

### 5.5 탑

#### 5.5.1 공통 규칙

#### 5.5.3 단계별 변화

**궁수탑** — 가장 앞선 적 하나를 빠르게 쏩니다. 사거리가 가장 깁니다.

- 1단계: 기본 — 가장 앞선 적 하나를 쏩니다.
- 2단계: 공격 속도 +10%.
- 3단계: 공격 속도가 한 번 더 +30% (합쳐 약 1.4배).
- 4단계: 공격 속도가 약 17배로 뛰어 화살이 이어진 빛줄기처럼 나갑니다. 한 발 피해는 6.3%로 낮아지고(밸런스 패치로 공격력 55% 감소), 쏠 때마다 탑 주변 적에게 바람 피해(40%)가 함께 입니다.

**저격탑** — 사거리 안에서 가장 단단한 적 하나를 크게 때립니다.

- 1단계: 기본 — 가장 단단한 적 하나를 크게 때립니다.
- 2단계: 사거리 +10%.
- 3단계: 사거리 +15% 더(합쳐 약 1.27배). 사거리가 길수록 그만큼 더 세게 때립니다.
- 4단계: 사거리 +10% 더(합쳐 약 1.39배). 사거리 끝자락(85% 밖)의 적에게는 확정 치명타입니다.

**대포탑** — 떨어진 자리 주변 적을 한꺼번에 때립니다.

- 1단계: 기본 — 착탄 지점 범위 피해.
- 2단계: 폭발 범위 +10%.
- 3단계: 폭발 범위 +15% 더(합쳐 약 1.27배). 폭발 피해도 +15%.
- 4단계: 폭발 범위 +20% 더(합쳐 약 1.52배). 맞은 적은 1.2초 뒤 한 번 더 터져 주변까지 피해를 줍니다.

**번개탑** — 번개가 가까운 적으로 이어 튑니다. 한 번 이어질 때마다 피해가 조금씩 줄어듭니다.

- 1단계: 기본 — 가까운 적 둘까지 연쇄합니다.
- 2단계: 셋까지 연쇄합니다.
- 3단계: 이어질 때 깎이는 피해가 15% 줄어듭니다.
- 4단계: 번개로 적을 처치하면 곁의 적에게 번개가 한 번 더 튑니다(한 번에 최대 3회).

**화염탑** — 범위 안의 모든 적을 5초 동안 불태웁니다. 화상 도트 피해가 단계마다 커집니다.

- 1단계: 기본 — 범위 안 모두에게 5초 화상. 화상 도트 피해 +15%.
- 2단계: 화상 초당 피해 +10%, 도트 피해 +20% (기본의 약 1.32배).
- 3단계: 화상 초당 피해 +20% 더, 도트 피해 +25% (기본의 약 1.65배).
- 4단계: 도트 피해 +30% (기본의 약 1.72배). 이미 불타고 있는 적에게 다시 불을 붙이면 불기둥이 솟아 추가 피해를 줍니다.

**독탑** — 하나에게 강한 지속 피해를 줍니다. 독은 장갑을 무시합니다.

- 1단계: 기본 — 독 피해.
- 2단계: 독 피해 ×1.10.
- 3단계: 독이 최대 5번까지 겹쳐 쌓여 피해가 커지고, 독에 걸린 적은 이동 속도가 15% 느려집니다.
- 4단계: 독이 5중첩이 되면 맹독이 폭발해 주변 적에게 그 적에게 실린 독 피해 전체가 번집니다. 터지면 중첩은 처음으로 돌아갑니다.

**서리탑** — 적의 이동 속도를 늦춥니다. 늦춘 적을 다른 탑이 잡으면 어시스트 골드를 받습니다.

- 1단계: 기본 — 이동 속도 50% 감소.
- 2단계: 감속 +10% (이동 속도 55% 감소).
- 3단계: 감속이 더 커집니다 (이동 속도 약 69% 감소).
- 4단계: 맞은 적을 3초 동안 완전히 얼려 멈춥니다.

**중력탑** — 멀리서 가장 뒤에 선 적 하나를 쏩니다. 끌어당긴 적을 다른 탑이 잡으면 어시스트 골드를 받습니다. 맞은 자리에 중력장이 생겨 둘레의 적을 그 자리로 끌어 모으고 잠깐 붙잡습니다. 뭉친 적에게 대포가 잘 듭니다.

- 1단계: 기본 — 가장 뒤의 적을 쏘고, 맞은 적 둘레(반경 80)의 적을 중심 쪽으로 반쯤 끌어당깁니다.
- 2단계: 중력장 지속시간 ×1.15.
- 3단계: 중력장 안의 적이 붙잡혀 있는 동안 중심으로 조금씩 더 끌려옵니다.
- 4단계: 중력장이 끝날 때 중심으로 끌어당긴 뒤 강한 중력 폭발이 일어납니다. 끌려온 적 최대 체력의 10%(보스는 3%)를 줍니다.

**보급소** — 골드를 만들고, 사거리 안에 선 이웃 탑의 공격력과 공격 속도를 올려 줍니다. 성채도 조금씩 회복합니다. 회복과 강화 효과는 단계마다 15%씩 커집니다.

- 1단계: 기본 — 이웃 탑 강화(+25%) · 골드 생성 · 성채 회복(초당 0.12).
- 2단계: 성채 회복과 이웃 탑 강화 효과가 ×1.15.
- 3단계: 효과가 ×1.30. 도움받은 탑이 공격할 때마다 보급소의 보급 게이지가 찹니다.
- 4단계: 효과가 ×1.45. 게이지가 가득 차면 성채가 즉시 회복되고(최대 체력의 6% × 단계 배수), 곁의 탑이 4초 동안 공격 속도가 대폭(+80%) 오릅니다.

**부식탑** — 맞은 적의 방어력을 4초 동안 깎습니다.

- 1단계: 기본 — 방어력 20% 감소.
- 2단계: 방어력 감소 ×1.10.
- 3단계: 부식된 적이 받는 모든 피해가 +10%.
- 4단계: 부식된 적이 죽으면 주변 세 명에게 부식이 옮겨 갑니다.

**성기사탑** — 서 있는 것만으로 성채가 받는 피해를 줄입니다. 여러 기를 세우면 겹칩니다(최대 45%). 보스 결전에서 스킬을 쓰면 사거리 안의 아군 모두에게 각자 체력의 60% 보호막이 생깁니다.

- 1단계: 성채가 받는 피해 6% 감소.
- 2단계: 성채가 받는 피해 12% 감소.
- 3단계: 성채가 받는 피해 18% 감소.
- 4단계: 성채가 받는 피해 24% 감소.

처음 화면의 "RPG 모드 들어가기"로 시작한다. 방어전과 별개의 모드이며, 대기실 없이 RPG 서버에 들어가 광장에 선다. 방 코드는 쓰지 않는다.

| ID | 기능 | 설명 |
|---|---|---|
| RPG-SRV-01 | 서버 | 서버 5개(`RPG1`~`RPG5`). 모두 서버 1에 먼저 모인다 |
| RPG-SRV-02 | 정원 | 서버마다 16명. 가득 차면 다음 서버로 자동으로 넘어가고, 모든 서버가 가득 차면 "모든 서버가 가득 찼습니다" 안내 |
| RPG-SRV-03 | 입장 | 판이 도는 중에도 언제든 들어올 수 있다. 입장 요청은 방장이 자리를 줄 때까지 1.5초마다 다시 보낸다 |
| RPG-SRV-04 | 방장 승계 | 방장은 2초마다 대기실 소식을 보낸다. 방장이 접속자 목록에서 사라지면 1초, 목록에는 있는데 소식만 끊기면 5초(앞선 사람 한 명마다 +2초) 뒤에 남은 사람이 이어받는다. RPG 서버에서는 "그 코드의 방을 찾지 못했습니다" 안내를 띄우지 않고 "광장으로 가는 중"에서 기다린다 |
| RPG-SRV-05 | 끊김 없는 승계 | 방장이 바뀌어도 세계를 새로 만들지 않는다. 이어받는 사람은 마지막으로 받은 스냅샷을 판정 세계로 바꾼다(`rpgPromote`). 모두의 맵 · 자리 · 체력과 몹의 번호 · 자리 · 체력 비율이 그대로 이어진다. 남은 손님은 새 방장에게 자기 기록(레벨 · 코인 · 스탯 · 가방 · 누르고 있는 방향)을 다시 보내고, 새 방장은 자리와 체력은 두고 기록만 싣는다. 화면은 다시 그리지 않는다(`RpgView` 를 방 코드로만 다시 만든다) |

### 6.1 캐릭터

| ID | 기능 | 설명 |
|---|---|---|
| RPG-CHAR-01 | 이름 · 코드 | 처음 한 번 정한다. 이름은 최대 8자이고 서버에서 겹치지 않아야 한다. 이어서 플레이어가 숫자 5자리 코드를 두 번 넣고, "꼭 적어 두세요" 확인 뒤 서버에 만든다. 같은 숫자 반복(00000)과 연속 숫자(12345 · 54321)는 받지 않는다. **둘 다 다시 바꿀 수 없고 코드는 되찾을 수 없다** |
| RPG-CHAR-02 | 직업 · 원소 · 성별 | 처음 게임을 시작할 때 정한다. **한 번 정하면 바꿀 수 없다**(관리자 캐릭터만 예외 — RPG-CHAR-09). 직업 3종 · 원소 6종 · 성별 2종 |
| RPG-CHAR-03 | 저장 | 이름 · 직업 · 원소 · 성별 · 레벨 · 경험치 · 코인 · 퀘스트 · 스탯 · 가방이 이 기기(`flg:rpg3`)와 서버(`rpg_chars` 표)에 남는다. 이 기기에는 바뀔 때마다, 서버에는 10초마다 바뀐 것이 있을 때와 나갈 때 저장한다 |
| RPG-CHAR-05 | 이어 하기 | 캐릭터 만들기 화면의 "코드로 이어 하기"에 이름 + 코드를 넣으면 서버 기록을 이 기기로 불러온다. 같은 이름으로 5번 틀리면 10분 막힌다(서버가 센다). 캐릭터가 있는 기기에서도 "다른 캐릭터로 이어 하기"로 바꿀 수 있다. 옆의 "새 캐릭터 만들기"로 이름 · 코드를 새로 정해 캐릭터를 하나 더 만들 수 있다. 이때 이 기기는 새 캐릭터로 바뀌고 지금 캐릭터는 서버에 남는다 |
| RPG-CHAR-06 | 동시 접속 | 나중에 들어온 기기가 이긴다. 이어 하기를 할 때마다 서버가 새 입장권을 주고, 먼저 있던 기기는 저장이 거절되어 "다른 기기에서 이 캐릭터로 들어왔습니다" 안내가 뜬다. 그 기기에서 다시 하려면 코드를 다시 넣는다 |
| RPG-CHAR-07 | 예전 캐릭터 | 서버에 없는 캐릭터(이 기능 전에 만든 것)는 캐릭터 만들기 화면에서 코드를 정하면 레벨 · 가방 그대로 서버로 옮긴다. 이름이 서버에서 겹치면 이때만 이름을 바꿀 수 있다. 정하지 않으면 이 기기에만 저장된다 |
| RPG-CHAR-09 | 관리자 | 서버 표의 `admin` 칸이 켜진 캐릭터. 이어 하기를 하면 서버가 관리자임을 알려 준다. 게임에서 최고 레벨(200)로 두고 코인은 쓰는 대로 99,999,999로 다시 채운다(`ADMIN`, `rpg.js`). 스탯은 다섯 모두 최대(250)로 두고, 초기화 물약을 마셔도 다시 최대가 된다. 보스 재료 · 강화석 일곱 가지는 늘 999개(`MAT_MAX`)로 두고, 쓰거나 팔면 바로 다시 찬다. 레벨 칸에 "관리자" 표시와 "무제한" 코인이 보인다. 직업 · 원소 · 성별은 모험 준비 화면에서 언제든 다시 골라 바꾼다(확인 없이 바로 저장 · 서버에도 저장). 관리자 캐릭터는 대시보드에서만 만든다 |
| RPG-CHAR-08 | 보안 | 표는 브라우저에서 직접 읽거나 고칠 수 없고 함수(`rpg_name_free` · `rpg_create` · `rpg_login` · `rpg_save` · `rpg_delete`)로만 쓴다. 코드는 bcrypt, 입장권은 sha256 해시로만 남긴다. 저장값은 브라우저가 보내므로 조작을 막지는 못한다. 문은 `supabase/rpg.sql` |
| RPG-CHAR-04 | 캐릭터 삭제 | 빨간 삭제 단추 → 이름을 똑같이 적어야 지워진다. 이름 · 직업 · 원소 · 성별 · 레벨 · 코인이 모두 사라진다. 서버에 있으면 서버 기록도 지운다(서버에서 못 지우면 이 기기 기록도 남긴다) |

직업:

| 직업 | 무기 | 특징 | 체력 배율 | 피해 | 간격 | 사거리 | 스킬 |
|---|---|---|---|---|---|---|---|
| 전사 | 검 | 붙어서 둘레를 한 번에 벤다 · 가장 튼튼하다 | ×1.35 | 34 | 0.55초 | 72 | 회오리 |
| 마법사 | 지팡이 | 원소 구슬을 쏜다 · 맞은 자리 둘레도 다친다 | ×0.9 | 44 | 1.1초 | 134 | 폭발 |
| 궁수 | 활 | 가장 멀리서 쏜다 · 한 마리를 노린다 | ×0.85 | 45 | 0.9초 | 158 | 화살비 |

원소(디펜스의 원소 탑 여섯에서 가져옴): 화염(태운다) · 서리(느리게 한다) · 번개(옆 토끼로 옮겨 붙는다) · 독(독을 스미게 한다) · 부식(더 아프게 맞게 한다) · 중력(둘레 토끼를 끌어당긴다). 평타에는 약하게, 큰 기술에는 세게 실린다. 스킬 이름은 "원소 + 직업 스킬"(예: 화염 회오리).

### 6.2 성장과 스탯

| ID | 규칙 | 값 |
|---|---|---|
| RPG-GROW-01 | 경험치 | 레벨 1→2는 30, 그다음부터 30씩 늘어난다(`30 × 레벨`). 최고 레벨 200(`LV_MAX`) |
| RPG-GROW-02 | 레벨 업 | 체력이 가득 차고 스탯 포인트 2를 받는다. 처음 만들 때도 2포인트 → 1~200레벨 합쳐 400포인트(스탯 하나에 250까지라 한 스탯을 가득 채우고 150이 남는다). 발밑에서 빛기둥이 솟고 고리가 퍼지며 "LEVEL UP" 글자와 소리가 난다(여러 레벨이 한꺼번에 올라도 한 번) |
| RPG-GROW-03 | 스탯 | 물리력 · 마법력 · 체력 · 치명타 확률 · 치명타 피해 5종. 스탯마다 최대 250포인트(`STAT_MAX`). 치명타 확률은 찍어도 전체 상한 80%를 넘지 않는다 |
| RPG-GROW-04 | 적용 | 스탯 창에서 올려 둔 포인트는 "적용"해야 반영되며 **적용하면 되돌릴 수 없다**. 창을 닫으면 적용하지 않은 포인트는 거둔다 |

| 스탯 | 기본 | 포인트당 | 효과 |
|---|---|---|---|
| 물리력 | 10 | +2 | 전사 · 궁수 공격력 |
| 마법력 | 10 | +2 | 마법사 공격력, 모든 직업의 화상 · 독 피해 |
| 체력 | 100 | +15 | 최대 체력(직업 배율을 곱함) |
| 치명타 확률 | 5% | +0.5% | 전체 상한 80% |
| 치명타 피해 | 150% | +1% | 치명타가 터졌을 때 피해 |

공격력 배율은 스탯 10을 1배로 본다(물리력/마법력 ÷ 10).

### 6.7 광장 상점

가격 · 확률 · 제한 수치는 모두 `src/game/shopData.js` 한 곳에 있다. 규칙은 `src/game/shop.js`, 화면은 `src/ShopPanel.jsx`.

## 9. 알려진 제약과 참고

- RPG 캐릭터는 코드를 정해 서버에 남긴 것만 다른 기기로 이어진다. 코드를 정하지 않은 캐릭터는 브라우저 저장소를 지우면 사라진다.
- 방어전은 방장이 나가면 방이 사라진다(방장 승계 없음). RPG 서버만 방장을 이어받고, 이때 세계를 새로 만들지 않고 그대로 이어 간다. 방장의 브라우저 탭이 판정을 맡으므로, 방장의 연결 · 성능이 전체 경험을 좌우한다.
- 방어전 탑 수치 · 능력 카드 · 보스 기술은 계속 조정 중이다. 수치가 바뀌면 이 문서의 표(자동 생성 부분)와 `src/game/towerInfo.js` · `updates.js` 를 함께 고친다.
- 판 위 소리 · 이펙트 일부는 이미지 파일이 없으면 코드 그림으로 대신한다. 그림 교체 방법은 `public/assets/game/README.md` 와 `ASSETS.md` 에 있다.
- RPG 모드는 현재 맵 3곳(광장 · 토끼 사냥터 · 늑대 사냥터) · 몹 2종과 보스 2종 · 퀘스트 1개이며, 이후 확장 대상이다.
