# 마지막 진혼곡 구현 기록

2026-11-17. 사용자 지시로 패치노트·공지에는 공개하지 않는다.

## 진행

1. BLOOD-001 활성, 캐릭터 레벨100, 직업 레벨100, 영구 압축형 연마20을 갖춘다.
2. 에르덴 도서관2층에서 「붉은 강이 거꾸로 흐른 밤」 마지막 쪽을 읽고 책 덮기를 누른다. 일반 캐릭터의 책은 그대로다.
3. 광장 분수의 낡은 수문 또는 예전에 열었던 입구에서 폐쇄 연구시설로 돌아간다. 북동쪽 RQ-0 문을 조사한다.
4. 개인 제3격리실에서 왼쪽 핵에 2단계 적혈탄, 중앙 원 위에서 혈역2초, 오른쪽 사슬3개에 혈검 실제 참격을 맞힌다.
5. 중앙 문이 열리면 유리관을 조사한다. RQ-0을 처치하고5.5초 동기화 연출을 마친다.
6. 가방이 가득 찼다면 공간을 비운 뒤 같은 유리관을 조사한다. 패배·재접속·직업 비활성화에도 봉인·처치 기록은 남는다.

## 수치와 산정

- 체력600,000. 전면 방패36,000, 정면 피해70% 감소. 적혈탄으로 방패를 깎고 파괴하면4초 동안 받는 피해1.4배.
- 1페이즈: 체력100~70%, 공격240, 반경150, 예고1.2초, 공격 뒤 대기3.6초.
- 2페이즈: 체력70~35%, 공격320, 혈량30 강탈, 반경230, 예고1.4초, 대기3.2초.
- 3페이즈: 체력35~0%, 공격420, 반경290, 예고1.3초, 대기2.2초. 새로운 파편 파동 연출.
- 모든 수치는 `requiemData.js` 한 곳. 혈막·방어구·회피는 기존 `hurtHero`를 따른다.
- 기존 고릴라 왕(110레벨)은 체력150,000/공격420. BLOOD-001의 물리력100포인트는 실제310, 기본 스킬1,240. 압축20의 2단 적혈탄은 기본15,004.
- 실제 게임 루프에서 캐릭터/직업100, 압축20, 물리력100포인트, 치명타 없는 적혈탄 반복은74.98초. 차징1.2초·대기0.7초·혈량 소모·혈역 회복을 그대로 적용했다. 피해를 피하는 시간은 제외했고 체력 전환26회에 필요한 회복은 공급했다. 실제 회피·물약 사용과 추가 스킬에 따라 시간은 달라진다. 초기15만은 약17초여서60만으로 조정했다.
- 기존 크림슨 레퀴엠 아이템 물리력+260, 혈계 추격18초, 5중첩 총7.2배와 풀차징·회복 규칙은 변경하지 않았다.

## 저장·권한·충돌 해결

- 기존 각성 후에는 조사물이 숨겨졌다. 각성자에게만 수문과 기존 개방 입구를 재노출하며 시험 대여/해금은 호출하지 않는다. 히든 직업 유일 소유 규칙은 그대로다.
- 이전 제한은 BLOOD-001이 다른 무기를 못 드는 방향뿐이었다. 반대 방향을 추가했다. `dropBlood`와 `cleanBag`에서 해제하지만 무기는 보존한다.
- 기존 몹 객체/스킬 충돌 판정을 활용하고 전용 표식 rq를 붙인다. 일반 허수아비 AI·체력 리필·드롭·경험치는 우회한다. 새 몹 종류 인덱스는 만들지 않는다.
- 개인 맵16개를 기존 MAP_IDS 끝에 추가. 기존 배열 번호는 그대로다. 영웅 줄59는 임시 연출, 몹 줄20은 전용 전투 상태. 소유자 식별자는 서버 스냅샷에서 기존 공개ID로 마스킹한다.
- 서버 입력은 책 읽기·조사·실제 스킬 의도뿐이다. 클라이언트 kill/reward/봉인 완료 요청은 없다. 전용 적중 콜백은 2단 본탄과 혈검의 실제 충돌 지점에서만 호출한다.
- 퀘스트 영구 상태는 가방 필드rq. 무기와 완료 플래그는 동기식 한 번에 변경하고 기존 캐릭터 JSON 저장으로 함께 보존한다. 가방 부족은 killed만 유지한다. 이미 무기가 있으면 추가하지 않고 완료한다.
- 공개 계정 생성·클라이언트 저장·게스트 참가에서 위조된rq/무기를 제거한다. 기존 서버 확정 기록은 클라이언트의 오래된 저장이 지우지 못한다. 전용 서버 저장 경로만 새 기록을 확정한다. 기존 관리자 명령어 지급은 유지한다.
- 거래와 장터는 공통 장부 `tradeOffer`와 `tradeExchange` 양쪽에서 거절한다. UI 목록에서도 제외한다. hold를 유지해 기존 상점·특가·상자·일반 드롭·월드보스 보상 후보에 들어가지 않는다. 일반 강화 경로는 그대로다.

## 그림과 화면

- `design/requiem/make.py`: RQ-0 검은 분절 갑옷, 단일 눈, 동력핵, 발광 혈관, 기계 손톱 및 문/핵/사슬/유리관 도트 원화.
- `design/requiem/make-fx.mjs`: 검토한 외부 pixelfx 코어(5294518)로 새로운 수렴·유리 파편·혈관·충격파 시트 생성. 외부 코드는 저장소에 포함하지 않는다.
- `public/assets/game/rpg/requiem/*.webp`: 실행용 투명 WebP. 프레임8개, 입자 최대32개를 미리 시트로 구워 실시간 입자 객체는 생성하지 않는다. 개인 맵만 그린다.
- 기존 `.shop` 창·공통 단추·갈색/금빛 UI 사용. 책 원문·책장·페이지 이동 유지. 전설 무기 화면은 기존 아이템/스킬 데이터에서 이름·물리력·스킬을 읽는다.
