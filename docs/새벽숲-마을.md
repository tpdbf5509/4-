# 새벽숲 마을

2026년 11월 5일. 광장 북쪽 문에서 이어지는 안전 마을이다. 추후 메인 이야기의 시작 장소로 확장한다. 지금은 탐방과 배경 대화만 제공한다. 퀘스트 수락·보상·진행 저장을 미리 만들지 않는다.

## 참고 조사와 적용

외부 이미지를 게임 파일로 복제하지 않고 구조·분위기를 참고했다. 그림은 내장 이미지 생성 도구로 새로 제작했다.

대화 화면은 사용자가 첨부한 예시처럼 하단의 넓은 대사 상자와 왼쪽 위로 올라오는 큰 인물 초상화를 쓴다. 게임의 기존 갈색·금빛 상점 틀과 공통 버튼을 유지한다.

## 연결과 구현

- `villageData.js`: 맵 크기 2200×1700. 광장 문 (900,180), 반경 46. 마을 도착 (1100,1390), 귀환 문 (1100,1640), 귀환 위치 (1030,240). 이름·좌표·충돌·대화·그림 규격·길(`VILLAGE_ROADS`)·광장(`VILLAGE_SQUARE`)·밭(`VILLAGE_FIELDS`)을 한곳에서 관리한다.
- 11월 6일 배치 정리: 큰길(남쪽 문 → 종탑 광장 → 촌장댁 문). 광장 동서 길 위쪽에 여관 (640,880) · 기록관 (1560,880), 아래 골목 위쪽에 약초집 (640,1380) · 대장간 (1560,1380), 동쪽 길 끝에 풍차 (1960,1060). 건물 좌표는 문 자리이고 짧은 갈림길이 문까지 닿는다. 주민은 자기 집 문 옆에 선다. 종탑은 광장 한가운데 (1100,985). 서쪽 · 동쪽 둘레길이 약초밭 · 풍차 텃밭을 지나 두 길을 잇는다. 나무는 길·건물·사람 자리를 비우고 둘레에 빽빽하게 놓는다(`villageArt.js` `treeSpot`).
- 11월 6일 배경 변경: 숲 느낌을 줄여 바탕을 밝은 들판 색(#86a05f)으로 바꾸고 들꽃을 흩었다. 마을 둘레에 나무 울타리(그림만, 충돌 없음)를 두르고 나무는 가장자리에 듬성듬성만 둔다(`treeSpot` · 확률 `.24` / `.05`). 북서 · 북동 들판에 밭 8곳(`VILLAGE_FIELDS`)과 건초 · 수레를 놓았다.
- 11월 6일 소품 12종(`design/village/props2.webp`, 자르기 영역은 `crops.json`): 천 가판대(여관 마당) · 채소 가판대 · 게시판 · 통과 상자(큰길 동쪽 모퉁이) · 장작 헛간(촌장댁 옆) · 연못(남서) · 울타리와 작은 대문(약초밭) · 울타리 · 건초(풍차 밭) · 수정 사당(대장간 동쪽) · 사과나무 3그루 · 돌다리. 돌다리는 `ground:1` 이라 충돌 없이 땅에 먼저 깔고(`drawVillageGround`) 사람이 위로 지나간다. 개울(`VILLAGE_BROOK`)은 바닥 그림이고 걸을 수 있다. 종탑은 크기 190 → 280, 충돌 반경 42 → 52.
- `rpg.js`: `dawnwood`를 기존 `MAP_IDS`의 맨 뒤에 붙인다. 안전 맵이며 몹 생성·공격·사냥터 PvP가 없다. 기존 광장 NPC 목록 순서를 유지한다. 11월 6일 명예판만 (900,256)에서 (700,256)으로 옮겼으며 그림·충돌·대화는 `HONOR_BOARD` 좌표를 함께 쓴다. 새 맵과 좌표는 기존 스냅샷으로 전달한다.
- `villageArt.js`: 길(중간점 곡선)과 광장·텃밭·울타리 바닥은 캐시한다. 건물·주민·소품·나무·사람은 발 위치로 정렬한다. 11월 6일 광장 문 주변에 덧칠했던 녹색 바탕과 연결 길은 삭제했다. 기존 광장 바탕 위에 문만 그리며 문 앞에서 바로 걸어 들어간다.
- `VillagePanel.jsx`: 인물 대사 첫 줄부터 차례로 보여 준다. 클릭·Enter·스페이스로 넘기고 Esc·닫기·바깥 클릭으로 닫는다. Tab 초점은 창 안에 두고 닫을 때 돌려준다. 다른 창을 열거나 대화 대상에서 멀어지면 닫는다.
- 주민 그림·건물·문 로딩 실패 시 코드 그림을 사용한다. 초상화만 실패하면 대사는 그대로 보여 준다. 광장에서는 문만 미리 읽고 나머지 풍경은 마을 진입 때 읽는다.

## 그림 규격

`public/assets/game/rpg/village/`에 투명 WebP 38장. 건물 6 · 주민 6 · 소품 20 · 대화 초상화 6. 모두 512×512다. 건물·주민·소품은 발 기준 (256,496)이며 초상화는 아래 끝에 맞춘다. 원본은 `design/village/`의 buildings·people·props·portraits 시트다. `crops.json`에 소품을 포함한 실제 자르기 영역을 남겼다. 화면 크기는 데이터의 `size`로 관리한다.

## 검증

`node tools/village.test.mjs`: 맵 차례 유지, 실제 이동 왕복, 주민 6명과 조사물 2곳의 클릭·접근, 퀘스트 오염 방지, 안전 판정, 손님 스냅샷, 건물 앞까지의 실제 길찾기를 확인한다. Playwright로 실제 RpgView의 대화 시작·넘김·닫기와 모바일 창 배치, 투명 그림 로딩을 확인한다. 기존 마우스 이동·레이스·결투·월드보스 시험과 빌드·린트·서버 번들을 함께 확인한다.
