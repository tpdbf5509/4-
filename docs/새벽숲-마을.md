# 새벽숲 마을

2026년 11월 5일. 광장 북쪽의 명예판 뒤쪽 문에서 이어지는 안전 마을이다. 추후 메인 이야기의 시작 장소로 확장한다. 지금은 탐방과 배경 대화만 제공한다. 퀘스트 수락·보상·진행 저장을 미리 만들지 않는다.

## 참고 조사와 적용

외부 이미지를 게임 파일로 복제하지 않고 구조·분위기를 참고했다. 그림은 내장 이미지 생성 도구로 새로 제작했다.

## 연결과 구현

- `villageData.js`: 맵 크기 2200×1700. 광장 문 (900,180), 반경 46. 마을 도착 (1100,1450), 귀환 문 (1100,1580), 귀환 위치 (1030,240). 이름·좌표·충돌·대화·그림 규격을 한곳에서 관리한다.
- `rpg.js`: `dawnwood`를 기존 `MAP_IDS`의 맨 뒤에 붙인다. 안전 맵이며 몹 생성·공격·사냥터 PvP가 없다. 기존 광장 NPC 목록과 좌표·순서를 유지한다. 새 맵과 좌표는 기존 스냅샷으로 전달한다.
- `villageArt.js`: 길과 텃밭·울타리 바닥은 캐시한다. 건물·주민·소품·나무·사람은 발 위치로 정렬한다. 광장 명예판 오른쪽으로 돌아 문에 닿는 길을 둔다.
- `VillagePanel.jsx`: 인물 대사 첫 줄부터 차례로 보여 준다. 클릭·Enter·스페이스로 넘기고 Esc·닫기·바깥 클릭으로 닫는다. Tab 초점은 창 안에 두고 닫을 때 돌려준다. 다른 창을 열거나 대화 대상에서 멀어지면 닫는다.
- 주민 그림·건물·문 로딩 실패 시 코드 그림을 사용한다. 초상화만 실패하면 대사는 그대로 보여 준다. 광장에서는 문만 미리 읽고 나머지 풍경은 마을 진입 때 읽는다.

## 그림 규격

`public/assets/game/rpg/village/`에 투명 WebP 26장. 건물 6 · 주민 6 · 소품 8 · 대화 초상화 6. 모두 512×512다. 건물·주민·소품은 발 기준 (256,496)이며 초상화는 아래 끝에 맞춘다. 원본은 `design/village/`의 buildings·people·props·portraits 시트다. `crops.json`에 소품을 포함한 실제 자르기 영역을 남겼다. 화면 크기는 데이터의 `size`로 관리한다.

## 검증

`node tools/village.test.mjs`: 맵 차례 유지, 실제 이동 왕복, 주민 6명과 조사물 2곳의 클릭·접근, 퀘스트 오염 방지, 안전 판정, 손님 스냅샷, 건물 앞까지의 실제 길찾기를 확인한다. Playwright로 실제 RpgView의 대화 시작·넘김·닫기와 모바일 창 배치, 투명 그림 로딩을 확인한다. 기존 마우스 이동·레이스·결투·월드보스 시험과 빌드·린트·서버 번들을 함께 확인한다.
