# 영상 무기 3종 — 2026-10-30

원본: `Video Project 2.mp4`(19.6초, 2520×1080, 30fps).
0.0초부터 19.5초까지 9프레임마다 총 66장을 추출했다. 원본과 프레임은 작업 폴더의 `reference-analysis/video2`에 보관하며 저장소에 영상을 싣지 않는다.

| 영상 구간 | 무기 / 스킬 | 확인한 시각 요소 |
|---|---|---|
| 약 1.0~3.3초 | 뇌명 지팡이 / 천뢰난무 | 둘레에 번갈아 떨어지는 청백색 낙뢰, 둥근 착탄광, 보랏빛 바닥 전류, 흐린 압력 고리 |
| 약 5.4~6.6초 | 자전궁 / 자전 관통 | 발사 순간 십자 섬광, 앞으로 이동하는 보랏빛 전격, 회전 고리와 전기 꼬리 |
| 약 7.5~13.0초, 14.1~17.7초 | 창뢰 쌍검 / 창뢰 비상참 | 청록색 충전광, 양옆 칼날과 직선 돌진, 짧은 명암 반전, 도착점 회전광과 V자 잔광 |

원본 3D 에셋·애니메이션·셰이더를 추출한 것은 아니다. 웹 RPG의 캔버스에 색과 순서를 재구성했다. 프레임마다 픽셀이 같은 복제는 검증하지 않았다. 영상에 대상이 없어 원본 피해량·범위·쿨타임은 알 수 없으므로 수치는 임시 밸런스다. 시간과 색·범위는 `stormWeaponData.js` 한 곳에서 조정한다.

관리자 채팅 명령:

```
/지급 나 뇌명 지팡이
/지급 나 자전궁
/지급 나 창뢰 쌍검
```

세 무기는 Lv100 전설이다. 일반 상점·특가·상자·관리자 자동 지급에서 제외한다. 기존 가방에서 장착하고 X를 사용한다. 쌍검은 키 또는 화면 버튼을 누르고 놓으면 발동한다. 최소 충전 0.3초, 최대 4초 자동 발동. 창 비활성화·채팅 열기·사망·경직·맵 이동·무기 교체는 충전을 취소한다.

판정은 방장이 한다. `ws.storm`을 스냅샷 46번 줄 끝에 추가해 방장 승계 때도 진행·타격 기록·PvP 피해 한도를 유지한다. 전격과 돌진은 지나간 선분을 검사해 빠른 이동에서도 타격 누락과 중복을 방지한다.

확인: 빌드 성공, lint 종료 코드 0(기존 경고 존재), 신규 11개와 기존 무기·전직을 포함한 73개 테스트 성공. 실제 RpgView를 로컬 Chromium에 띄워 세 지급 명령, 장착, X 발동·충전·해제, 화면 버튼을 누른 뒤 영역 밖에서 놓기까지 확인했다. 브라우저 오류 0. 이 브라우저 시험은 외부 서비스 요청을 막고 수행했다.

## 새 무기 그림 (2026-10-30)

내장 이미지 생성 도구로 뇌명 지팡이·자전궁·창뢰 쌍검 원화를 제작했다. 원본은 `design/weapons/storm-generated.png`다. `tools/cut-storm-weapons.py`가 투명도를 유지해 128px 아이콘과 256×128 양손 쌍검 시트를 만든다. 기존 경로를 유지하고 `rpgArt.js`의 손잡이 좌표를 새 그림에 맞췄다. `tools/storm-weapons-art.mjs`도 새 자르기를 호출하므로 임시 SVG로 덮어쓰지 않는다.

확인: 빌드 성공. 린트 성공(기존 경고 유지). 무기 판정 시험 성공. 로컬 Chromium에서 세 아이콘의 128×128 로딩과 세 직업의 실제 `drawRpg` 장착 모습을 확인했다. 쌍검 양손 표시와 활줄 방향을 확인했고 브라우저 오류는 없었다. 배포 상태는 작업 보고에서 별도로 확인한다.
