# 월드보스 장비 이미지

2026년 10월 23일 내장 이미지 생성 도구로 제작했다. 프롬프트에 “2D 도트형 RPG 게임 (2D pixel art RPG game)”을 명시했다. 투명 배경, 7열×3행, 총 21개 장비를 요청했다.

원본: `/workspace/generated_images/exec-340ec912-b2c5-47ec-860f-520f0be5f3cd.png`. 원본은 보존하고 무손실 WebP 인코딩만 변환했다. 게임은 `public/assets/game/rpg/items/world-equipment.webp`(1916×821)를 사용한다. 그림 수정 없이 UI는 격자 위치로 표시하고 캔버스는 같은 원본의 해당 칸을 그린다.

행 순서: 드래곤·거대 뱀·고대 번개 기계. 열 순서: 전사 무기·마법사 무기·궁수 무기·투구·갑옷·바지·신발. 각각 붉은 비늘/검정/금색, 녹색/보라/상아, 청동/청록 번개를 사용한다. `worldEquipmentData.js`가 좌표를 정의한다.
