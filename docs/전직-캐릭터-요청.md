## 모든 그림에 똑같이 넣는 프롬프트

```
Use the attached reference sheet as the strict style and character guide.
Create a character turnaround sheet in exactly the same chibi anime style, line weight, soft shading, proportions and size as the reference.
Keep the SAME two characters from the reference row of the base job (same face, eyes, hair style and hair color for the boy and the girl).
Only the outfit and gear change, as an upgraded "advanced class" version. Keep the white hooded coat and brown leather belts as the base so it still feels like the same character, then add the class details below.
Layout: 2 rows, 4 poses each, same order as the reference.
Top row = boy, bottom row = girl. Left to right: front (facing viewer, turned slightly to the right), side (facing left), back, three-quarter view facing left.
All 8 figures the same height as each other, standing, feet on the same baseline, evenly spaced with wide empty gaps, nothing overlapping.
Transparent background (if not possible, pure flat white #FFFFFF). No text, no labels, no icons, no ground shadow, no frames.
Aspect ratio 3:2, at least 2048 px wide.
```

## 무기를 지운 그림(bare) 만들 때

`armed` 그림을 넣고 이렇게 요청한다.

```
Edit this image: remove only the held weapons (sword / bow / pistols / staff / book). Keep everything else pixel-identical: same characters, same poses, same hand and arm positions (hands empty, in the same place), same size, same positions on the canvas, same background. Keep the knight's shield on the arm.
```
